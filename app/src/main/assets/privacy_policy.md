#### Overview

VTOP Mate is an independent student-developed application that helps students access and organize information available through their authorized VTOP account.

This application is not affiliated with, endorsed by, or maintained by VIT-AP University.



#### Information We Collect

##### User Credentials

* Registration Number
* VTOP Credentials
* Selected Semester Preferences

##### Academic Information

The application may retrieve and store:

* Timetable
* Attendance
* Marks
* Grade History
* Examination Schedules
* Outing Information
* Student Profile Information

##### Optional Google Services

When enabled:

* Google Account Email
* Calendar Synchronization Preferences

##### Notifications

The application may store:

* Firebase Cloud Messaging Token
* Notification Preferences



#### Data Usage

Information is used only to:

* Display academic information
* Generate reminders
* Sync calendar events
* Deliver notifications
* Improve application functionality



#### Data Storage

* Most information is stored locally on the user's device.
* The developer does not sell or share personal information with advertisers.



#### Third-Party Services

This application may use:

* Firebase
* Google Sign-In
* Google Calendar APIs

Each service operates under its own privacy policy.



#### Data Removal

Users may remove stored information by:

* Logging Out
* Clearing Application Data
* Uninstalling the Application



#### Contact

Questions regarding privacy may be submitted through the project's GitHub repository.
